# Wing's Buy n Sell

Production-oriented starter repository for the Wing's Buy n Sell website.

## Current State

The repository intentionally contains:

- an implemented homepage visual reference
- mock vehicle data
- project-specific specifications
- architecture/database/design plans
- the owner's Next.js, Supabase, and Tailwind agent rules

The full application is **not** implemented yet.

## Stack Direction

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase
- TanStack Query
- React Aria Components
- React Hook Form + Zod
- nuqs
- next-safe-action
- Lucide React
- GSAP + ScrollTrigger
- Lenis

## Start

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:3000
```

## Before Using an AI Coding Agent

Read:

- `AGENTS.md`
- `docs/`
- `rules/`

The agent should treat those files as the source of truth.

## Important

Messenger and phone are intentionally not configured yet.

Supabase is intentionally not wired yet.

Mock testimonials must not be presented as real customer testimonials in production.
